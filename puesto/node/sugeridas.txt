# Las librerías SUGERIDAS para un repositorio de TypeScript (ORE 0050 L6·2·3):
# lo que el panel Libraries ofrece añadir con un clic. Es un atajo, no un límite:
# cualquier paquete de npm se declara a mano en `package.json`.
#
# Una línea por librería, separada por tabuladores:
#   nombre  área  descripción  [paquete de tipos, que va a devDependencies]
#
# ⛔ Medidas el 2026-10-04 antes de entrar: se instalan con `npm install
#   --ignore-scripts` (sin scripts de instalación, como la capa) y funcionan
#   SIN RED (`--network none`, como el puesto), cada una con una llamada real.
#   Fuera, con su porqué: @huggingface/transformers (onnxruntime-node baja sus
#   binarios en un script y los modelos de internet), onnxruntime-web (141 MB),
#   danfojs (TensorFlow.js), natural (lee `.env` al importarse) y
#   zod-to-json-schema (Zod 4 ya lo trae). Una nueva entra con la misma medida.
#
